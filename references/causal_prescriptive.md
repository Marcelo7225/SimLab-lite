# Causalidad Y Prescripcion

## Postura Epistemica

La simulacion produce hipotesis, no verdad causal. Usar lenguaje de incertidumbre:

- "La simulacion sugiere..."
- "El mecanismo probable..."
- "Conviene validar..."
- "Confianza baja/media/alta..."

## DAG Textual Base

```text
exposicion_al_estimulo -> claridad_de_beneficio -> confianza -> intencion_de_accion
prueba_social -> reduccion_de_riesgo -> confianza
precio -> friccion -> abandono
comparacion_competidor -> credibilidad_relativa -> preferencia
influenciador_experto -> legitimidad -> intencion_de_accion
malentendido_narrativo -> desconfianza -> rechazo_publico
```

## Variables

- Tratamientos: mensaje, oferta, precio, canal, prueba social, garantia, demo, urgencia.
- Mediadores: claridad, confianza, relevancia, riesgo percibido, valor percibido, identificacion cultural.
- Outcomes: clic, lead, compra, compartir, recomendar, preguntar, rechazar, criticar.
- Confusores: awareness previo, afinidad de marca, poder adquisitivo, experiencia pasada, categoria, contexto noticioso.

## Formato De Hipotesis

```text
H1: Si [tratamiento], podria aumentar/disminuir [outcome] en [segmento] porque [mecanismo].
Evidencia simulada:
Confusores:
Como validar:
Confianza:
```

## Prescripcion

Cada recomendacion debe tener:

- Decision: que hacer.
- Razon social: patron observado en agentes.
- Razon causal: mecanismo probable.
- Segmento/canal.
- Riesgo.
- Experimento.

## Experimentos Recomendados

1. Mensaje: beneficio funcional vs prueba social.
2. Oferta: descuento vs garantia vs bonus.
3. Canal: LinkedIn/Search/Meta/WhatsApp segun contexto.
4. Landing: claim principal vs evidencia.
5. Secuencia: educar primero vs vender directo.
6. Objecion: responder certificado/precio/tiempo/confianza.
